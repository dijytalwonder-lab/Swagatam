WHAT THIS IS
Swagatam is a festival status-poster maker for businesses and influencers
(WhatsApp Status size, English + Hindi). Today every screen is drawn in code
(CSS gradients, emoji, a few game illustrations). This file lists the art to
generate so each page can look rich and branded. Each prompt has a [key], a size
and a ready-to-paste prompt. Generate, save as shown, then tell me and I will wire
the images into the app (the build script already converts PNG -> small WebP).

STYLE (same family as Diwali Delivery Dash / Little Krishna / Dashavatara)
Glossy cartoon-storybook art: soft rounded shapes, thick clean outlines, soft
cel shading with a bright top-left highlight, jewel-bright festival colours,
tiny sparkles, cheerful and welcoming. Cute but respectful - never mocking of
any deity, faith or community. Mobile-game polish.

BRAND PALETTE (anchor every prompt to these)
  Deep plum ........ #4a1250 / #2b0833      Marigold ........ #f59e0b / #ffb703
  Magenta-plum ..... #7a1d6f                Saffron-orange .. #f97316
  Cream paper ...... #fff7ea                Rose ............ #c2185b
  Antique gold ..... #d4a017 / #f6e7a8      Success green ... #12a38a
  (In-app text uses the font "Baloo 2" and is drawn by the app, so NO LETTERING
   goes inside any image.)

GLOBAL TAIL - paste this at the end of EVERY prompt
"Glossy cartoon storybook style, thick clean outlines, soft cel shading with a top-left
highlight, saffron / marigold / deep-plum / gold palette with jewel accents, cheerful
and welcoming. No text, no letters, no numbers, no watermark, no baked drop shadow."

TRANSPARENCY - IMPORTANT (lesson from the game assets)
Several earlier PNGs had a grey/white CHECKERBOARD painted into the pixels instead of
real transparency, which shows up as boxes in the app. For every "transparent" asset:
  - export a real alpha PNG, OR
  - ask for "isolated on a flat pure-magenta #FF00FF background, nothing else in the
    frame" and I will key it out, OR
  - ask for "isolated on pure white" only for items with no white in them.
Never accept an image that shows a checker pattern. Full-screen backgrounds are
opaque and need no transparency.

GLOBAL RULES
- Portrait phone app. Full-screen art is 1080x1920 (9:16). On a phone it is shown
  at about 360x640 CSS px, so keep details bold; nothing important smaller than ~40 px.
- Leave the top ~110 px (status bar) and bottom ~150 px (navigation) free of key detail.
- Keep large calm areas where the app places text and buttons (marked "EMPTY ZONE").
- Light comes from the top-left. Rounded corners everywhere. No hard black outlines
  on UI parts: use a deep-plum (#2b0833) outline instead.
- Every asset must work on both cream (#fff7ea) and deep-plum (#2b0833) unless it
  is a full background.
- Folder suggestion: www/img/ui/<key>.png (screens), www/img/art/<key>.png (festival
  art), www/img/poster/<key>.png (poster parts).
